# Custom Backend Management System

A custom backend management system built with Spring Boot to manage and deliver dynamic content for a dedicated frontend website. The project provides RESTful APIs, database integration, content management features, and deployment-ready architecture for scalable web applications.

## Features

- RESTful API architecture using Spring Boot
- MySQL database integration
- Dynamic content management
- Image upload and management support
- Frontend integration support (React-based frontend)
- Docker containerization
- Cloud deployment support with Google Cloud Run
- Scalable and maintainable backend structure
- Object-oriented architecture with reusable components

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Docker
- Google Cloud Run
- Maven
- REST APIs
